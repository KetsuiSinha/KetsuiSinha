## Featured Work

### Pulse: AI Client Update Generator
`FastAPI` `Next.js` `PostgreSQL` `Celery` `Redis` `LLM`

An LLM-powered platform that automates client status updates by pulling activity from GitHub, Linear, and Slack.

- Reduced manual update generation from 2-3 hours per client each week to under 15 minutes
- Built an ingestion pipeline with an activity normalization layer and relevance filter
- Added tone calibration from user examples, improving draft relevance scoring by 45%
- Captures user edits as a feedback loop to continuously improve output quality
- Async LLM jobs via Celery and Redis, multi-client review dashboard, and Stripe-based 3-tier billing
- Deployed on Vercel and Railway

### HospiBot: Multilingual Healthcare Chatbot
`Dialogflow` `Node.js` `MongoDB` `Socket.io` `AWS`

A production conversational assistant serving patients across Web, WhatsApp, and Telegram in English, Hindi, and Marathi.

- 500+ monthly patient interactions at 78% automation, with sub-2-second responses and a 4.2/5 satisfaction score
- Estimated 40 staff hours saved per week
- Intent classification, entity extraction, and multi-turn context for appointment booking, prescription refills, lab reports, and FAQs
- Symptom triage with confidence-based fallback (0.7 threshold) and real-time handoff to a human nurse
- Channel-adapter webhook architecture with CRM/EMR integration, audit logging, and patient consent handling
- CI/CD through GitHub Actions, deployed on AWS EC2 with MongoDB Atlas
